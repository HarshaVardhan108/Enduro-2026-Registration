Connect Live Google Sheets

To receive form submissions directly into your own Google Spreadsheet in real-time, follow these 3 simple steps:

  1. Create a new spreadsheet at sheets.new
  2. Click Extensions → Apps Script and paste the snippet below:
Google Apps Script (Code.gs)
function doPost(e) { var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet(); // Set headers on first run if empty if (sheet.getLastRow() === 0) { sheet.appendRow([ "Timestamp", "Reg ID", "Full Name", "Email", "Phone", "College", "Year", "Branch", "Track", "Experience", "SOP", "LinkedIn" ]); } var p = e.parameter; sheet.appendRow([ new Date(), p.regId || '', p.fullName || '', p.email || '', p.phone || '', p.college || '', p.year || '', p.branch || '', p.track || '', p.experience || '', p.statement || '', p.linkedin || '' ]); return ContentService .createTextOutput(JSON.stringify({ "status": "success" })) .setMimeType(ContentService.MimeType.JSON); }
  1. Click Deploy → New Deployment → Select type: Web App. Set Who has access to Anyone, click Deploy, and copy the Web App URL!
